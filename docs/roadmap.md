# Roadmap

This roadmap keeps the project useful as an open-source prototype while avoiding premature claims about production readiness.

## Current

- Deterministic LINE-style companion simulator.
- LINE webhook handling for text and image message events.
- Local event metrics and fake-payment validation loop.
- Companion tone templates for common senior daily-chat scenarios.
- Metadata-only image intake with no OCR claim.

## Next

- Add a maintainer release checklist for deterministic QA.
- Expand safety tests for high-risk scam and distress wording.
- Add optional LLM integration behind explicit configuration.
- Add OCR intake only after privacy, consent, and safety wording are reviewed.
- Add Codex-assisted pull request review and release note generation.

## Not Planned Yet

- Real payment collection.
- Medical, legal, financial, or emergency advice.
- Automatic family monitoring dashboard.
- Production deployment guidance for real senior users without a safety review process.
